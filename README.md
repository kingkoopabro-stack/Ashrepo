Rare Candy Reserve — Hugo static site

What this adds:
- Minimal Hugo scaffold (config, content, layouts, styles)
- Sample product using a Stripe Payment Link placeholder
- Music page (place MP3s in static/music/)
- Instructions for placing the logo:
  Put your attached logo at static/images/logo.png (filename: Rare Candy Reserve LOGO.png)

Quick local preview (requires Hugo installed):
1. Install Hugo (extended not required) on your PC or Pi.
2. From repo root: hugo server -D
3. Open http://localhost:1313

Deployment notes in deploy/ folder.
